先拿门锁，再进屋放东西

① 守卫表 friend_player_guards —— 门锁
INSERT INTO friend_player_guards (player_id)
VALUES (B)
ON DUPLICATE KEY UPDATE player_id = player_id
只有一列 player_id。执行完 = 握住 B 的门把手（行锁），不改任何数据。此时还没加好友。
→
② 好友表 friendships —— 房间里的东西
INSERT IGNORE INTO friendships
  (player_id, friend_id) VALUES (B, C)
INSERT IGNORE INTO friendships
  (player_id, friend_id) VALUES (C, B)
这才是真正加好友：写两条双向边（B→C、C→B）。此刻锁还在手上，安全。

类比：守卫行 = 每个玩家门口的一把门锁（门牌号是 player_id）；上面那条 SQL = 「把门推开并握住门把手」；friendships 的 INSERT = 「进屋把礼物放进房间」。锁门和放东西是两回事。
